# Dynamic API Studio 操作型界面整改设计

## 目标

在保留现有导航、页面结构和业务模型的基础上，将界面整改为清晰、紧凑、真实可操作的后台工作台。优先使用项目现有的 shadcn/ui 组件模式和 Tailwind CSS，修复无效操作、可访问性缺陷、固定宽度布局和重复控件实现。

本轮历史数据继续使用现有 mock 数据，但筛选、分页、选择、复制和导出必须具备真实的前端行为。

## 设计方向

采用“操作台优先”方案：保留深色侧栏、顶部栏、项目资源侧栏和 API 工作区；将页面内容统一为紧凑工具栏、表格、分页和可调整分栏。避免营销式布局、过量卡片和无法兑现的操作入口。

## 页面结构

### 应用壳

- 保留现有 176px 深色主导航和顶部面包屑。
- 主内容使用动态视口高度，避免移动浏览器地址栏造成的高度错误。
- 主内容提供跳转链接和明确的 `main` 锚点。
- 侧栏图标操作要么接入真实功能，要么移除；不保留无效按钮。
- 项目卡片使用 TanStack Router `Link` 作为导航语义，支持键盘、打开新标签页和辅助技术。

### API 设计器

- 独立设计器使用两栏可调整布局：左侧 API 定义，右侧工作流。
- 移除未使用的第三栏轨道及 `min-w-[1380px]` 强制宽度。
- 项目详情中的设计器继续使用 `ResizablePanelGroup`，并共享相同的真实操作工具栏。
- 保存草稿和发布按钮位于设计器上下文内部，确保可以访问当前 API 定义。
- 顶部应用栏不再展示无法访问设计器状态的假按钮。

### 历史页

- 调用历史采用“指标摘要、筛选工具栏、数据表、分页”结构。
- 测试历史采用“历史列表、请求信息、响应结果”结构；宽屏保持三栏，较窄窗口允许区域自然换行或滚动，不对整个页面设置超大最小宽度。
- 表格容器负责必要的局部横向滚动，页面本身不被固定宽度撑开。
- 指标数值使用等宽数字样式，筛选栏在空间不足时换行。

## 组件策略

新增或完善以下 shadcn 风格基础组件：

- `Checkbox`：替换参数和 Schema 表格中的原生 checkbox。
- `RadioGroup`：替换请求 Body 类型的手工 radio 实现。
- `Select`：替换状态、请求方法、字段类型和数据源选择器。
- `Tooltip`：用于所有没有文字标签的图标按钮。
- `Pagination`：统一首页、API 侧栏、测试历史和调用历史分页。
- `Toast` 或等价的 shadcn 状态提示：反馈保存、发布、复制和导出结果，并提供 `aria-live`。

继续复用现有 `Button`、`Card`、`Table`、`Tabs`、`Dialog`、`AlertDialog` 和 `Resizable`。页面区域不使用嵌套卡片；Card 仅用于独立指标、列表项和真正需要边框的工具区域。

## 交互设计

### 历史筛选与分页

- 调用历史支持时间范围和执行状态筛选。
- 测试历史支持测试名称、执行人和状态筛选。
- 筛选条件变化后页码回到第 1 页。
- 重置恢复默认筛选条件。
- 分页总数、当前页、上一页和下一页状态均由筛选结果派生。
- 本轮状态保留在页面内；接入真实后端接口时再映射到 URL 查询参数。

### 导出

- 调用历史导出当前筛选后的完整结果，而不是仅导出当前页。
- CSV 使用稳定列顺序并处理引号、逗号和换行。
- 浏览器通过 Blob 和临时下载链接生成文件，完成后释放 URL。

### API 设计器操作

- 保存草稿调用现有保存 mutation。
- 发布将当前定义状态设为 `published` 后调用保存 mutation。
- 工作流支持添加下一步、复制和删除。
- 响应 Schema 支持新增根字段、新增子项、复制和删除。
- 参数、Schema 字段和工作流步骤的删除使用 `AlertDialog` 确认。
- 新增实体使用现有 `createId` 生成稳定 ID。

### 复制操作

- 请求预览和响应结果使用 Clipboard API 复制格式化 JSON。
- 成功和失败均展示状态提示；失败提示给出下一步信息。

## 可访问性

- 应用提供跳过导航链接，主内容具有稳定 ID。
- 所有输入控件具备 `id`、`name` 和可访问标签；非认证字段设置 `autocomplete="off"`。
- 图标按钮提供 `aria-label` 和 Tooltip；装饰图标设置 `aria-hidden="true"`。
- 点击标题折叠编辑器的行为改为语义化 button。
- CodeMirror、Tabs、Dialog、Resizable 和自定义列表项保留明显的 `focus-visible` 样式。
- 异步状态通过 `aria-live="polite"` 传达。
- Skeleton、Dialog 和其他动画遵循 `prefers-reduced-motion`。

## 内容与格式

- 加载文案统一使用省略号字符 `…`。
- 日期使用 `Intl.DateTimeFormat`，数字使用 `Intl.NumberFormat`。
- 数值列和指标使用 `tabular-nums`。
- 长名称、路径和描述使用 `min-w-0`、`truncate`、`line-clamp` 或 `break-words`。
- 不隐藏核心滚动区域的滚动条。

## 错误与空状态

- 加载、空数据和请求错误使用统一的轻量状态区域。
- 保存、发布和测试执行期间按钮禁用并显示进行中状态。
- 错误信息说明失败原因及可执行的下一步。
- 不显示尚未接入功能的按钮；所有可见命令必须有真实行为。

## 测试范围

- Reducer：工作流和响应 Schema 的新增、复制、删除。
- 历史数据工具：筛选、分页边界和 CSV 转义。
- 组件：图标按钮可访问名称、搜索控件标签、分页禁用状态。
- 回归：现有 CodeMirror 和首页调用日志测试继续通过。
- 完整验证命令：`pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm build`。
- 启动开发服务器后检查首页、项目列表、项目 API 设计器、测试历史和调用历史的桌面与窄窗口布局。

## 非目标

- 本轮不新增测试历史或调用历史后端接口。
- 本轮不引入新的全局状态管理库。
- 本轮不重做品牌、配色或路由架构。
- 本轮不为手机尺寸重新设计完整 API 编辑能力，只保证窄桌面和常见平板宽度下结构可用。
